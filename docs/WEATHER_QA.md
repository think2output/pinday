# 날씨 대안 구현·확인 — 2026-10-25

브랜치 `feat/weather` (← `origin/main` `20ac311`, PR #13 병합 후). 기획서 6-7, 와이어프레임 `Weather-*`·`Empty-weather`.

## 사용자 결정

- 실내 대안은 **거리 제한 없이** 가까운 실내 장소 3곳을 보여준다("멀어도 외부보다 실내가 낫다").
- 실내·야외가 함께 있는 곳도 실내에서 지낼 수 있으면 실내로 친다. 장소별 예외 28곳 추가(`docs/분류표.md`, `scripts/build-places.mjs`의 `INDOOR_IDS`). 실내 79 → 107곳.
- 날씨는 일정 화면과 같은 부산 대표 지점 하나로 본다.

## 구현

- `src/app/weather/`. `page.tsx`가 장소의 이름·지역·분류·좌표·실내 여부와 승인 도슨트 ID를 넘기고 `<Suspense>`로 감싼다.
- 구성: 제목·조건 줄(조건 바꾸기 창) → 날짜 카드(n일차·날짜·하늘·강수확률 또는 최저/최고 기온) → 그날 일정. 장소마다 실내/야외 표시.
- 비·눈 예보가 있는 날에만 야외 장소 아래 "대신 갈 만한 실내 장소" 최대 3곳: 가까운 순, 직선 2km 안의 이야기(승인 도슨트) 있는 곳은 맨 앞, 이미 일정에 있는 곳은 제외. "직선 약 ○km · 분류 · 이야기 있음", 이야기 있으면 '▶ 이야기' 링크.
- '이 장소로 바꾸기'를 눌러야만 기존 `tripActions.replaceInDay`로 바뀐다(날짜·순서 유지, 새 장소는 후보함에도 추가). 바꾼 장소는 "실내 · 바꾼 장소 · 원래 ○○" + 되돌리기.
- 되돌리기: 원래 장소로 다시 바꾸고, 바꿀 때 후보함에 새로 들어갔던 장소면 후보함에서도 뺀다. 원래 장소가 그새 다른 날에 들어갔으면 되돌리지 않고 안내.
- '바꾼 장소' 기억은 여행 저장소를 고치지 않으려고 이 탭의 sessionStorage에만 둔다(`swapMemo.ts`). 창을 닫으면 표시·되돌리기는 사라지고 바뀐 일정은 남는다(화면에 안내).
- 예보 전·자료 없음·강수 판단 불가·불러오기 실패·지난 날짜는 각각 따로 표시하고 맑음이나 '비 없음'으로 바꾸지 않는다. 이때는 대안을 보여주지 않는다.
- 빈 상태: 일정이 하나도 없으면 날씨 카드는 보여주고 "일정을 넣으면 대안을 알려드려요" + 비 예보 날 안내 + 후보 있음 → 언제 갈까?, 없음 → 어디 갈까?. 그날만 비었으면 "이 날은 아직 일정이 없어요".
- 반송공원(2907087)처럼 좌표가 잘못된 장소는 대안을 찾지 않고 "지도 위치를 확인할 수 없는 장소라…"로 안내. 실내 후보에서도 제외.
- `/weather?day=N`이면 그 일차로 연다. 언제 갈까?의 '날씨 확인 · 준비 중'을 `/weather?day=지금 일차` 링크로 교체(위치는 지도 아래 그대로).
- 날씨 기호는 컬러 이모지 대신 글자 모양(`\uFE0E`). 노란색은 선택된 비 오는 날 카드의 우산과 대안 제목의 작은 조명 점에만.
- 공통 파일(여행 저장소·tokens.css·SiteHeader) 수정 없음. 일정 화면의 `scheduleModel.ts`·`useScheduleWeather.ts`는 수정 없이 가져다 씀.

## 확인 결과

Chrome headless + DevTools Protocol, 별도 임시 프로필, 개발 서버 `http://localhost:3000`, 1440×1000·390×844.

- 테스트 118개(새 날씨 대안 계산 8개 포함)·린트·빌드 통과.
- 두 폭 모두 가로 넘침 없음, 본문 버튼·링크 44px 이상.
- 실제 예보(10.25 2시 발표): 1일차 비 강수확률 최대 70%, 2·3일차 구름많음·맑음. 비 오는 날 광안리해수욕장·민락수변공원에 실내 대안 3곳씩, 반송공원은 위치 안내(검증 시점 기록).
- 가짜 응답(비/맑음/예보 전)으로 세 상태 문구 확인. 날씨 API 502: 다시 시도 버튼, 대안 숨김.
- 바꾸기 → 저장소 1일차 같은 자리 교체·후보 +1 → 되돌리기 → 원래 장소·후보 수 복구.
- 일정 없음 빈 상태, `?day=2`·`?day=3` 열기, 일정 화면 '날씨 확인' 링크.

## 남은 것

- 웰니스 분류(요가 스튜디오·다이빙 풀·스파 등)도 실내라 대안에 나온다(광안리 근처 1~3순위). 관광 대안으로 어색하면 뒤로 미루거나 뺄지 사용자 결정 필요.
- 와이어프레임의 휴대폰 하단 고정 '이동 확인·날씨 확인' 막대는 아직 지도 아래 일반 위치.
- 장소별 날씨(장소 좌표 격자)는 쓰지 않는다. 필요하면 `placeId`로 부를 수 있지만 호출 수가 늘어난다.
