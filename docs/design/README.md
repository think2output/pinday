## 컨셉: 핀 조명

PinDay의 "핀"을 두 가지로 겹친다: 지도에 꽂는 핀 + 전시실 작품을 비추는 핀 조명. "부산이라는 전시실에서 내가 고른 곳에 조명이 켜진다."

## 사용자가 좋아한 것 (살릴 것)

- **마우스를 따라다니는 조명**: 블록 지도 위에서 손전등처럼 빛 원이 커서(휴대폰은 누른 자리)를 따라감. 위에서 내려오는 조명이 아니라 **정면에서 비추는** 느낌.
- **구를 누르면 조명이 "탁" 켜짐**: 빛이 퍼지며 살짝 깜빡인 뒤 고정, 핀 아이콘이 꽂힘. 켜진 곳이 생기면 지도 바탕이 한 톤 어두워짐. 움직임 줄이기 설정이면 연출 없음.
- **흰 바탕** (따뜻한 종이색은 싫어함).
- **전시 벽 + 조명 원 (이번 주 부산 이야기)**: 사용자가 보낸 갤러리 사진(벽에 둥근 스포트라이트, 그 안에 사진 여러 장, 아래 이름) 참고. 네모 사진을 둥근 빛 안에 거는 방식이라 공공누리 3유형(변경금지) 사진을 자르지 않아도 된다.
- **기울어진 사진 콜라주 + 핀 꽂힌 지도 조각** (레퍼런스: 인용 카드 앱, komoot).
- **짧은 메인 카피**: "핀을 꽂으면, 이야기가 켜져요" / "부산 어디에 조명을 비춰볼까요?" (홈 첫 문구는 아직 확정 아님)
