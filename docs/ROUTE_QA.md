## 구간 UI 재정리 (이전 기록)
- 사용자 피드백: 짧은 도보에도 큰 상자를 써 옆에 의미 없는 빈 공간이 많고 읽는 흐름이 끊김.
- 큰 테두리 상자 제거. 시간·수단 선택·길 보기를 한 행에 정렬. 데스크톱 도보는 거리도 같은 행.

- 휴대폰은 요약→장소/구간 목록→지도. 데스크톱은 요약 바로 아래 목록, 오른쪽 지도 유지.
- 테스트 140개·린트·빌드 통과. 390/1440 Chrome 재검증: 승하차 기본 접힘과 펼침·수단별 링크·키보드·오류·14일·44px·넘침 없음.
- 도보 행 높이 390px에서 76px, 1440px에서 60px. 데스크톱 요약과 목록 사이 간격 24px 이하. 접은 노선 요약과 펼친 환승 안내 모두 사진 확인.
- 최신 사진: `docs/design/route-ux/qa-compact-{transit,mixed,walk,expanded}-{390,1440}.png`. 시험 응답(경로 호출 12건 가로챔, 실제 카카오 경로 호출 0건). 이전 `qa-transit/qa-mixed` 사진은 수정 전 기록.
- 화면 배치는 사용자 검토 대기. 실제 API 활성화·한도·응답 재검증은 아래 기존 미확인 항목과 동일.
