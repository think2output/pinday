# 어떻게 갈까? 확인 기록

2026-10-25, `feat/route`. 이전 시안 사진(a, a2, b)은 실제 기능 검증 기록이 아니다.

- `npm test`: 140개 통과. 수단별 API·캐시 분리, 동시 중복 요청, 캐시 만료, 한도 오류 후 재조회, 잘못된 수단/중복 조건 거절 포함.
- `npm run lint`, `npm run build`: 통과.
- 390px·1440px Chrome 별도 프로필에서 확인. `node scripts/qa-route.mjs`로 재현.
- 시험 응답으로 대중교통·도보 혼합, 구간별 독립 선택, 환승 단계별 승하차, 도보 카카오맵 링크, 실패 후 재시도 확인.
- 키보드 화살표 날짜 이동, 빈 날, 1곳인 날, 좌표 오류 장소, 14일 탭, 저장 전 자동 여행 확인.
- 가로 넘침 없음. 자체 버튼·링크 44px 이상(카카오 SDK가 생성한 요소 제외).
- `localhost:3000`에서 카카오 지도 SDK 로드·번호·선 표시 확인. 별도 빌드 서버 `localhost:3100`에서는 지도 실패 안내와 목록 유지 확인. 주소별 등록 차이로 추정하나 원인은 확정하지 않았다.
- 기존 사용자 여행 데이터는 건드리지 않고 별도 Chrome 프로필의 시험 데이터만 사용했다. 외부 카카오 경로 API 호출 0건(화면의 경로 요청 10건 모두 시험 응답으로 처리). 지도 SDK/타일은 실제 로드.
