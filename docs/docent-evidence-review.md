# 대표 장소 도슨트 근거 1차 검수 — 2026-10-24

검수자: Codex(AI). 사람의 최종 검수는 아직 하지 않았다. 해설·음성 생성도 하지 않았다.

대표 장소 10곳을 골라 수집 원문을 읽고, 장소 연결의 적절성·서로 다른 출처의 충돌·현재 정보로 쓰면 안 되는 부분을 확인했다. 긴 글 전체를 승인하지 않고 사용할 문단과 범위를 따로 남겼다. 아래 ‘초안 후보’는 명시한 범위 안에서만 글을 써볼 수 있다는 뜻이며, 역사·동네·방문정보 세 부분을 모두 채울 수 있다는 뜻은 아니다.

## 실제로 확인한 문제

1. **공식 데이터끼리도 내용이 충돌한다.** 25의용단 TourAPI 소개는 일제강점기 독립운동 기념관으로 설명한다. 국가유산청 상세와 [부산시 충렬사관리사무소](https://www.busan.go.kr/cys/coremains04)는 임진왜란 때 항전한 25인의 의용을 기리는 제단으로 안내한다. 이 장소의 TourAPI 원문을 해설 입력에서 제외하도록 검수 파일에 기록했다. 원본은 고치거나 지우지 않았다.

2. **이야기에 잘못된 국가유산 지정종류가 섞여 있다.** 부산 이야기 `1363`은 조계문을 국보로 서술한다. [국가유산포털 안내판](https://www.heritage.go.kr/heri/cul/culGuidePostDetail.do?ccbaCpno=1122114610000&ccgbGbtype=IND&ccgbGbtypeNo=1&pageNo=1_5_0_0)은 조계문을 보물로 안내한다. 이야기 `1363` 전체를 초안 입력에서 제외한다. 범어사 안의 조계문 설명은 장소가 가깝다는 이유가 아니라 원문에 명시된 건물명·범어사 경내 맥락을 확인해 별도 관람 범위로만 골랐다. 원본 `nearby-only` 관계는 그대로 둔다.

3. **HTML 속성만으로 연결된 자료가 있다.** 이야기 `1218`은 본문 텍스트가 사실상 없고 이미지·링크 중심이다. 대표 장소 중 감천문화마을·해운대해수욕장·태종대·복천박물관에 연결됐지만 텍스트 해설 근거에서 제외했다. **추가 확인으로 정정:** `857`은 본문에 ‘감천 문화마을도 아니고’라는 띄어 쓴 부정·비교 언급이 있었다. 최초 검수에서 이를 속성만의 연결로 잘못 설명했으며, 제외 판단은 유지하되 이유를 ‘다른 장소와 구분하는 언급’으로 바로잡았다. HTML 파서와 공백 정규화를 적용한 회귀 테스트로 확인했다.

4. **이름이 언급됐다고 그 장소를 설명하는 것은 아니다.** 감천문화마을에 연결된 `846`은 다른 전망대와의 비교이고, 복천박물관에 연결된 `1184`는 다른 명소의 주차장 위치 안내다. 해운대에 연결된 `795`의 해당 부분은 미포 설명이다. 이를 각각 마을·박물관·해수욕장 자체의 역사나 특징으로 옮겨 쓰지 않도록 제외했다. `same-place`는 자동 연결 후보이지 사실 검증이나 글 전체의 장소 일치를 뜻하지 않는다.

5. **현재 정보와 과거 소개를 구분해야 한다.** 이야기 `309`의 168계단 모노레일 체험 안내와 [부산시보의 경사형 엘리베이터 소개](https://www.busan.go.kr/news/totalnews01/view?curPage=2&dataNo=72876)는 시설 표현이 다르다. 현재 이용 안내는 오래된 모노레일 원문에서 가져오지 않는다. 해운대에 연결된 `2617`의 2025~2026 겨울 행사 일정은 2026-10-24 현재 일정으로 재사용하지 않는다. 태종대·해운대의 `1408`은 2023~2024 관광지 선정 글이므로 해당 선정 기간을 생략해 현재 정보처럼 쓰지 않는다.

6. **별칭 때문에 빠진 자료도 있다.** ‘동아대학교 석당박물관’은 부산 이야기의 ‘석당박물관’과 자동 연결되지 않았다. 원본 `303`·`1178`에 박물관 설명이 있다. ‘부산 구 백제병원’도 `58`·`1178`의 ‘옛백제병원’과 연결되지 않았다. 별칭 연결 후보를 기록했으며, 수집 규칙·408곳 원본·자동 집계는 아직 바꾸지 않았다. `1178`의 백제병원 연도 표현과 국가유산청의 건립 연도는 개원·건물·동별 연혁 차이를 추가 확인한 뒤 써야 한다.

7. **마을 형성의 맥락을 단순화하면 안 된다.** [사하구 공식 감천문화마을 안내](https://saha.go.kr/tour/contents.do?mId=0101010000)는 태극도 신도와 피란민의 집단 거주지 형성을 함께 설명한다. 피란민만으로 전체 형성사를 설명하는 원문은 보완이 필요하다. 이번에 고른 문단은 골목·주거·벽화의 관찰 범위로 제한했다.

8. **유구 개수는 집계 범위부터 맞춰야 한다.** 복천박물관 TourAPI의 ‘200여 기’와 [복천박물관 공식 고분군 안내](https://museum.busan.go.kr/bokcheon/tumbpark)의 ‘191기’는 차이가 있다. 시점·조사 범위·집계 대상이 같은지 확인하지 못했으므로 정확한 개수는 해설에서 보류한다. 공식 페이지는 검색 결과로 확인했으며 직접 열기는 시간 초과였다. 석당박물관의 1959년 창설·2009년 이전 개관은 [박물관 공식 연혁](https://www.donga.ac.kr/museum/CMS/HistoryMgr/list.do?mCode=MN071)과 대조했다.

## 검수 기록 사용법

`data/docent/reviews/representative-2026-10-24.json`에 장소별 판단과 다음 정보를 담았다.

- 선택한 출처 ID·주소와 실제 원문의 문단 범위(`start`, `end`, `originalText`). 위치는 원문 문자열의 JavaScript 인덱스이며 끝 인덱스는 포함하지 않는다.
- 원문·장소별 파일의 SHA-256. 이후 수집 원문이 바뀌면 예전 검수를 그대로 적용하지 말고 재검수한다.
- 제외할 출처 ID와 이유, 작성할 수 있는 범위, 추가 공식 확인 링크.
- 목록에 없는 출처는 **미검수**로 남긴다. 검수 파일에서 선택하지 않은 주변 유산을 자동으로 초안에 넣으면 안 된다.

`classification.humanReview: pending`은 유지한다. 이 표본 검수가 당시 자동 충분 후보 191곳 전체를 승인한 것은 아니다. `reviewer`도 AI로 명시해 사람 검수 완료와 구분했다. 이후 수집 규칙 v2에 선택 문단·제외 출처·출처별 원문 해시 검사를 적용했으며, 408곳 재집계는 충분 후보 83곳 / 소개만 324곳 / 직접 소개 없음 1곳이다. 파일 전체 해시는 최초 검수 시점 기록으로 유지하고 재수집 시 원문 해시를 검사한다. 해설 생성 코드는 아직 없으며 나중에 만들 때도 미검수·제외·재검수 자료를 걸러야 한다.
