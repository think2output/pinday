# 분류표 초안 — 취향 유형 · 실내/야외

2026-10-24 · Claude Code 작성 · **초안 (사용자 확인 전)**

TourAPI 4.3 실제 데이터(부산, `data/places/raw/`)의 분류 이름으로 만들었다. 분류 이름은 TourAPI 새 분류체계(`lclsSystm`)의 "중분류 > 소분류"다. 확정하면 DECISIONS에 기록하고 이 문서의 "초안" 표시를 지운다.

## 받은 데이터

| 파일 | 내용 | 개수 |
| --- | --- | --- |
| tourapi-12-attractions | TourAPI 관광지 | 351 (사진 있음 324) |
| tourapi-14-culture | TourAPI 문화시설 (박물관·전시관·미술관·도서관·공연장 등) | 125 |
| tourapi-28-leports | TourAPI 레포츠 (캠핑장·산책로·수상레저) | 60 |
| busan-theme-travel | 부산테마여행정보: 장소 하나가 아니라 **주제별 여행 이야기** (도보여행 64, 이색여행 183) | 247 |
| tourapi-lcls-names | 분류 코드 → 이름 표 | 246 |

- 16개 구·군 모두 관광지가 있다(가장 적은 곳: 사상구 5, 연제구 7).
- 부산테마여행정보는 "초량이바구길", "동래역사여행"처럼 긴 본문(상세내용)이 있는 이야기 글이다. 장소 목록보다는 **이번 주 부산 이야기 · 도슨트 근거**로 쓰기 좋다.
- 사진 저작권 표시: 공공누리 1유형 134곳, 3유형(변경금지) 190곳, 표시 없음 27곳. 3유형 사진은 자르거나 덧칠하지 않는다(기획서 11장).

## 사용자가 정할 것

1. **문화시설(박물관 등)을 넣을까?** DECISIONS는 "주말 버전 데이터는 관광지만"이다. 그런데 국립해양박물관·임시수도기념관 같은 박물관·기념관은 TourAPI에서 "관광지"가 아니라 "문화시설"로 분류돼 있다. 넣지 않으면 동래성 시간 여행자 취향과 날씨 대안(실내 장소)이 약해진다.
   - 추천: 문화시설 중 **박물관·전시관·미술관·기념관·과학관·수족관만** 넣는다(약 63곳). 도서관·공연장·학교·문화원은 뺀다.
2. **레포츠는?** 추천: 주말 버전에서는 뺀다. 캠핑장·골프장 위주라 이야기할 거리가 적다.
3. **한 장소가 여러 취향에 들어가도 될까?** 추천: 된다(예: 태종대 = 파도 탐험가 + 바다). 정렬할 때 1순위로 맞는 취향을 먼저 보여준다.

## 취향 유형 → 분류 (초안)

| 취향 유형 | 맞는 분류 (중분류 > 소분류) | 예시 장소 |
| --- | --- | --- |
| 이바구길 골목 산책자 | 도시.지역문화관광 > 골목길, 문화거리 · 마을관광지 · 둘레길 / 농.산.어촌 체험 > 체험마을 / 복합관광시설 > 관광단지 / 역사유적지 > 근대건축물 | 감천문화마을, 깡깡이 예술마을, 흰여울문화마을, 보수동책방골목, 차이나타운 |
| 광안리 노을 감상가 | 자연경관(하천‧해양) > 해변. 해수욕장 · 섬 · 항구/포구 / 랜드마크관광 > 다리 / 대교 · 분수 · 등대 / 도시공원 > 주제공원(수변공원) | 광안리해수욕장, 다대포해수욕장, 광안대교, 다대포 꿈의 낙조분수, 민락수변공원 |
| 동래성 시간 여행자 | 역사유적지 (전부) / 역사유물 > 탑ㆍ비석ㆍ기념탑 / 종교성지 > 불교 · 기독교 · 기타 / (문화시설) 박물관 · 기념관 | 동래읍성지, 복천동 고분군, 충렬사, 범어사, 부산 구 백제병원, 국립해양박물관 |
| 태종대 파도 탐험가 | 자연경관(하천‧해양) > 해안절경 / 랜드마크관광 > 타워 / 전망대 / 자연경관(산) (전부) / 자연공원 > 생태관광지 · 자연휴양림 · 지질공원 / 테마공원 > 테마파크 / 기타체험 > 유람선/잠수함관광 | 태종대, 이기대, 오륙도, 황령산 전망대, 금정산, 해운대리버크루즈 |

- 어느 취향에도 안 들어가는 분류: 도시공원(근린·시민·소공원), 웰니스(온천·찜질방), 산업관광, 기타체험(먹자골목·업체), 교통시설. 이름순으로만 보인다.
- "기타체험 > 기타체험관광"(27곳)에는 국제시장 먹자골목 같은 장소와 주식회사 이름이 섞여 있다. 일반 회사 이름으로 보이는 곳은 목록에서 빼는 것을 추천한다(목록은 정리 단계에서 사용자에게 보여주고 확인).
