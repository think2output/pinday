# 어디 갈까? 구현·확인 — 2026-10-25

브랜치 `feat/explore` (← `fix/trip-page`). 사용자 승인 범위: 장소 API를 연결한 목록·검색·분류·취향 정렬·후보함·카카오 지도와 휴대폰 목록 서랍.

## 구현

디자인은 기능 연결을 위한 초안이며 최종 확정이 아니다. 홈의 확정 디자인 기준을 적용한 상태로, 사용자가 배치·밀도·지도와 목록 비율을 검토한 뒤 조정한다.

- `/explore`를 `<Suspense>`로 감싸 여행 저장소를 읽는다. 저장된 지역·기간을 이어받으며, 저장 정보가 없으면 부산 전체와 기본 기간을 표시만 한다.
- `/api/places`의 반복 지역·분류·검색·정렬 조건으로 최대 500개를 받는다. 현재 408곳 전체를 받을 수 있으므로 지도에 핀을 표시하고 지도가 움직일 때 이미 받은 장소를 화면 범위로 거른다. 화면 밖 장소를 담아둔 후보함은 유지한다.
- 정렬 기본은 취향이 있으면 내 취향순, 없으면 이름순. 분류 선택은 데이터의 실제 categoryCode를 쓰며 빠른 분류 버튼과 전체 분류 선택 제공.
- 데스크톱은 목록·지도·후보함 3단, 휴대폰은 지도 위에 목록 서랍과 미리보기, 하단 후보 수 및 후보함 창. 서랍은 버튼·키보드와 터치 드래그로 펼치거나 접을 수 있다.
- 후보 담기·빼기는 기존 `tripActions` 사용. 후보함에서 빼면 기존 규칙대로 일정에서도 제거하고 화면에 알린다. 사진은 미리보기에서 원래 비율로 표시하고 출처·공공누리 유형 표기.
- 지도는 공식 JS SDK와 MarkerClusterer 사용. 묶음 핀은 누르면 확대, 개별 핀과 목록 선택은 미리보기로 연결. 선택 핀은 노란색, 담은 핀은 ✓.
- 실패 시 지도와 API를 각각 재시도할 수 있고 지도 실패 중에도 목록·후보함은 계속 동작.
- 이야기 생성 전이므로 이야기 필터·듣기·도슨트 이동을 제공하지 않음. 취향 테스트 UI와 일정 화면은 아직 없어 준비 중 표시. 날짜에 배치하기 버튼은 해당 화면 구현 전까지 비활성 상태.

공통 여행 저장소·디자인 값·공통 컴포넌트는 수정하지 않았다. 키 값은 읽거나 기록하지 않고 설정 여부만 확인했다. 실제 지도는 `http://localhost:3000`에서 확인.

## 원본 좌표 1건 주의

`반송공원`(2907087)의 데이터 좌표는 위도 19.69442748 / 경도 117.9925662504로 부산에서 크게 벗어난다. 전체 범위 확대에 그대로 사용하면 부산이 제대로 보이지 않아, 탐색 화면에서 위도 34~36·경도 128~130의 넓은 표시 범위를 벗어난 좌표는 핀·자동 확대·지도 이동에서 제외한다. 이 범위는 행정 경계가 아니라 잘못된 원본 좌표로 인한 확대 방지용이다.

원본·API는 수정하지 않았으며 정확한 좌표는 공식 자료 확인 후 별도 보완해야 한다. 이 장소는 목록과 검색에 남기고 ‘지도 위치 확인 필요’ 안내와 후보 담기를 제공한다. 지도 안 목록에도 이 확인 필요 장소는 예외로 남긴다. 현 데이터에서는 지도 표시 대상 407곳, 목록 전체 408곳. 실제 원본 오류를 재현하는 회귀 테스트 포함.

## 확인 결과

Chrome headless + DevTools Protocol, 별도 임시 프로필. 1440×1000·390×844에서 개발 서버 화면 확인. 배포용 빌드는 별도로 통과했으며 실제 휴대폰 기기의 네이티브 날짜 선택창은 별도 확인이 필요하다.

- 부산 전체 408곳, 자동 기간 표시만으로 localStorage 저장하지 않음.
- 조건 창에서 수영구 선택 → API의 정확한 지역 조회 개수와 목록 수 일치. 복수 지역 수영구·해운대구의 67곳도 확인.
- 광안리해수욕장 이름 검색·분류 선택·없는 검색어·검색/분류 초기화. 빠르게 검색어를 바꿔도 마지막 검색 결과 표시.
- 후보 담기·미리보기에서 빼기·새로고침 후 유지, 검색·분류를 바꿔도 후보 보존. 실제 `/trip`으로 이동하면 후보 수 반영.
- 휴대폰 후보함 창 열기·닫기, 서랍 버튼 및 실제 터치 드래그 펼치기.
- 이미지 자연 비율과 표시 비율 일치, 자르기(`object-fit: cover`) 없음.
- 조건 창의 역전 날짜는 적용을 막고 오류 표시. 조건 창 취소 동작 확인.
- 지도 개별 핀 실제 클릭 → 미리보기, 묶음 핀 실제 클릭 → 확대, 실제 지도 드래그 → 경계·목록 변경.
- 키보드 Enter로 목록 선택, Space로 후보 담기.
- 장소 API 요청을 강제로 실패시키면 해당 영역만 오류, 다시 시도 후 복구.
- 지도 SDK 요청을 차단하면 지도 오류 안내와 목록 408곳 유지, 후보 담기 가능. 차단 해제 후 지도 다시 시도로 복구.
- 저장된 취향을 주입해 취향순에서 전체 408곳 유지 및 맞는 곳 우선, 이름순 전환 확인.
- 일정에 넣은 후보를 빼면 후보와 일정에서 함께 제거.
- 홈 시작 버튼 → `/explore` 실제 이동. 내 여행 페이지에 갔다가 탐색으로 돌아오면 지도 핀 재생성 확인(Next.js 화면 보관·복귀 대응).
- 앱이 만든 표시된 버튼·선택창·입력칸의 44px 크기, 두 화면의 가로 넘침 없음·페이지 높이 유지·내부 목록 스크롤 확인. 카카오가 제공하는 로고·저작권·기본 지도 컨트롤은 변경하지 않음.
- 브라우저 JavaScript 실행 예외 없음.
