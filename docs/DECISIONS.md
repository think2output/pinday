기획서와 다르면 이 파일이 우선한다. 새 결정은 맨 아래에 날짜와 함께 추가한다.

## 내 여행 정보
- 2026-10-23 지역 저장 값은 시·도 전체 이름 기준(부산광역시, 부산광역시 수영구). 화면 표시는 짧게(수영구).
- 2026-10-23 지역을 안 고르면 부산 전체. 메뉴로 바로 들어오면 "부산 전체 + 내일부터 2박 3일" 자동, 장소를 처음 담을 때 저장.
- 2026-10-23 일정에 넣어도 후보함에 남는다. 같은 장소는 하루에만.
- 2026-10-24 기간을 줄이면 사라진 날짜의 장소는 "아직 날짜 없는 곳"으로 옮기고 알린다.
- 2026-10-24 여행 초기화는 지역·기간, 후보함, 일정, 취향 유형까지 모두 지운다. 확인 창 + 되돌리기.
- 2026-10-24 일정은 날짜가 아니라 일차(1일차, 2일차…) 기준으로 저장한다. 출발일을 옮겨도 일정은 그대로 따라가고, 기간을 줄이면 뒤쪽 일차부터 사라진다(알림 문구도 "3일차 장소 2곳…").
- 2026-10-24 기간 최대 14일은 출발일·도착일 포함 14일(13박 14일).
- 2026-10-24 후보함에서 빼면 일정에서도 빠진다. 초기화 뒤 다른 변경을 하면 되돌리기는 사라진다.
- 2026-10-23 "이어서 계획하기": 후보 없음 → 어디 갈까?, 후보 있음 → 언제 갈까?. (상단 "내 여행"은 2026-10-25 결정으로 별도 `/trip` 페이지에 연결.)

- 2026-10-24 날씨 대안: 알림은 자동, 일정 교체는 사용자가 누를 때만.

## 데이터·API
- 2026-10-24 대중교통·도보 경로는 카카오맵 경로 API, 자동차는 카카오모빌리티. ODsay 제외(하루 30회).
- 2026-10-24 부산관광아카이브 제외(공개 API 없음). 대신 부산근현대역사관 아카이브 API.
- 2026-10-24 국가유산청 API는 XML, 서버에서만 호출.
- 2026-10-24 기상청 단기예보는 공공데이터포털이 아니라 기상청 API허브(apihub.kma.go.kr) 키로 부른다(기획서 9장의 "공공데이터포털 신청 완료"는 틀림).
- 2026-10-24 TourAPI는 4.3(KorService2). 부산은 법정동 코드 `lDongRegnCd=26`으로 거른다(옛 `areaCode=6`은 대부분 비어 있어 관광지 351곳 중 114곳만 나옴). 분류는 새 분류체계 `lclsSystm1~3`을 쓴다.
- 2026-10-23 키는 서버 `.env`에만. 카카오 지도 JavaScript 키만 화면 코드(도메인 등록으로 보호).

## 기술 스택
- 2026-10-24 화면·서버: Next.js(App Router) + TypeScript 한 프로젝트. 외부 API 호출과 키는 서버 코드(Route Handler)에만, 화면 코드에는 카카오 지도 JavaScript 키만.
- 2026-10-24 배포: Vercel 무료(Hobby, 비상업). GitHub 연결 자동 배포 + 브랜치별 미리보기 주소. 광고·유료화를 붙이면 유료 요금제로 바꿔야 한다.
- 2026-10-24 데이터베이스 없음. 장소 목록·도슨트 해설은 로컬 스크립트로 만들어 레포에 JSON 파일로 저장 → 사람 검수 → 커밋하면 배포. 월 1회 갱신도 같은 방식.
- 2026-10-24 날씨·경로·최근 소식은 서버에서 불러온 결과를 짧게 캐시해서 다시 쓴다.
- 2026-10-24 카카오 지도 도메인 등록: `localhost`와 Vercel 주소.
- 2026-10-24 비교했던 다른 안: React + Cloudflare(설정이 둘로 나뉨), React + Python 서버(배포 두 곳, 무료 서버 잠듦). 주말 오픈과 에이전트 교대 작업에 불리해서 제외.

- 2026-10-24 스타일 방식: Tailwind. 디자인 값은 `src/styles/tokens.css` 한 파일에 이름(bg-accent, rounded-card 등)으로 모으고, 화면 코드에 색 코드를 직접 쓰지 않는다. 시안을 고르면 이 파일 값만 바꾼다.
- 2026-10-24 Next.js 16.4 + React 19. 줄바꿈은 LF로 통일(`.gitattributes`).

## 도슨트 해설 초안
- 2026-10-25 사용자 지시("최소 비용으로"): OpenAI 선불 $5 안에서 진행. 모델은 `gpt-6-luna`(공식 가격 100만 토큰당 입력 $0.1·출력 $0.5), 추론 낮음, 응답 저장 안 함. 스크립트 기본은 미리보기이고 `--run`일 때만 호출, `--budget`으로 상한.
- 2026-10-25 첫 시험은 대표검수의 '범위 제한 초안 후보' 7곳만. 입력은 검수에서 고른 문단뿐이며 원문 해시가 다르면 건너뛴다. 자료 보완 2곳·보류 1곳·자동 충분 후보 83곳은 생성하지 않았다.
- 2026-10-25 초안은 `ai-draft`·`humanReview: pending`·`publishable: false`로 저장하고, 사람 검수 문서(`docs/docent-drafts-review.md`)에서 확인한 뒤에만 공개한다. 근거가 없는 부분은 비워 "근거 자료에 관련 내용이 없어요"로 표시한다.

- 2026-10-25 사용자 승인: 사람 검수는 AI가 문장별 원문 대조 결과를 요약 보고하고 사용자가 승인하는 방식으로 한다. 해설이 한 문장뿐인 곳은 공개하지 않는다(해운대해수욕장 비공개, 6곳 공개). 연도 범위가 있는 소개 글이 근거면 "○○~○○년 소개 글 기준" 표시.
- 2026-10-25 도슨트 화면은 승인된 해설만 보여준다. 최근 소식과 국가유산청 공식 음성은 이용 조건 확인 전이라 넣지 않고, 듣기는 브라우저 내장 음성만 쓴다. 이야기가 6곳뿐인 동안 목록의 검색·지역 고르기는 생략한다.

## 도슨트 근거 수집 1차 기준
