## 공개 범위와 사람 검수

- AI 초안 7곳 중 **6곳 공개**: 25의용단·범어사·감천문화마을·168계단·태종대·복천박물관. **해운대해수욕장은 해설이 한 문장뿐이라 비공개**(사용자 결정).
- 검수 방식: AI(이 세션)가 모든 문장을 근거 원문과 대조해 표로 요약 보고 → 사용자(PM)가 "한 줄만 아니면 공개"로 승인. `data/docent/drafts/*.json`의 `humanReview`에 방법·날짜 기록.
- 화면은 `publishable: true` + `humanReview.status: approved` + 자동 검사 문제 0건인 해설만 읽는다(`src/lib/server/docent.ts`). 생성 스크립트는 승인된 해설을 `--force` 없이 덮어쓰지 않는다.
- 태종대: 2023~2024 관광지 소개 글 근거라 화면에 "2023~2024년 소개 글 기준이라 지금과 다를 수 있어요" 표시(사용자 승인).

## 구현

- `/docent`: 제목 → 내 여행 장소의 이야기(후보함에 공개 이야기가 있을 때만, 일정 일차 표시) → 모든 이야기 6곳 카드(사진·구·분류·요약). 검색·지역 고르기는 6곳뿐이라 생략하고 안내 문구.
- `/docent/[id]`: 사진(자르지 않음, 출처·공공누리 유형) → 구·분류·이름 → 한 줄 요약 → 역사와 문화 / 동네의 특징 / 방문 전 알아두기(없으면 "근거 자료에 관련 내용이 없어요") → 현장 관람 포인트(없으면 숨김) → 근거 자료 목록·AI 해설 안내(만든 날·사람 확인 날) → 근처에 이런 곳도(직선거리 2km·최대 3곳, 이야기 있으면 링크).
- 문장 끝 번호를 누르면 그 문단 아래 근거 원문이 펼쳐진다.
- 듣기: 브라우저 내장 음성(한국어 목소리 있을 때). 요약·세 부분·관람 포인트를 차례로 읽고 지금 읽는 부분에 "지금 듣는 중". 멈춤·다음 부분. 한국어 목소리가 없으면 "이 기기에서는 듣기를 지원하지 않아요".
- 행동: 후보함 담기/빼기, 일정에 넣기(일차 고르기 창, 각 날 장소 수, 이미 일정에 있으면 막고 언제 갈까?로 안내), 카카오맵 길찾기(공식 URL `map.kakao.com/link/to/이름,위도,경도`). 휴대폰은 하단 고정, 데스크톱은 오른쪽 따라오는 칸.
- 공개되지 않은 장소 주소(예: `/docent/126081`)는 "이 장소의 이야기는 아직 없어요" + 모든 이야기로.
- 언제 갈까? ⋯ 메뉴: 공개 이야기가 있는 장소는 "▶ 이야기 보기" 링크, 없으면 "이야기 준비 중"(비활성).
- 최근 소식(지역 언론)은 이용 조건 확인 전이라 넣지 않았다. 국가유산청 공식 음성도 이용 조건 확인 전이라 쓰지 않는다.
