## 구현

기능 구현 완료. 디자인은 홈의 확정 기준(흰 바탕·먹색·노란 조명·모서리 0)을 적용한 초안이며 최종 확정 아님.

- `src/app/schedule/`. `page.tsx`가 장소 408곳의 이름·지역·분류·좌표만 넘기고 `<Suspense>`로 감싼다.
- 네 영역: 날짜 탭 → 그날 일정 → 아직 날짜 없는 곳 / 그날 지도. 데스크톱은 왼쪽 목록·오른쪽 지도(스크롤 시 따라옴), 휴대폰은 탭 → 지도 → 일정 → 날짜 없는 곳 순서.
- 후보함이 비면 "아직 담은 장소가 없어요" + 어디 갈까?에서 모으기. 랜덤 뽑기는 준비 중 문구.
- '+ N일차에 넣기'는 지금 보고 있는 날 맨 뒤에 바로 넣는다. 넣은 뒤 다음 장소 버튼으로 초점 이동.
- ⋯ 메뉴: 이야기 보기 · 준비 중(비활성), 순서 앞으로/뒤로, N일차로 옮기기, 일정에서 빼기. 데스크톱은 장소 아래 펼침, 휴대폰은 아래에서 올라오는 창.
- 순서 바꾸기: ⋮⋮를 마우스·손가락으로 끌기, ⋮⋮ 선택 후 ↑↓(Home/End). 결과는 화면 알림 문구로도 읽어준다.
- 저장은 기존 `tripActions.addToDay`·`moveToDay`·`removeFromSchedule`·`reorderInDay`만 사용. 저장소·tokens.css·공통 컴포넌트 수정 없음.
- 지도: 순서 번호 네모 + 짧은 점선. "점선은 방문 순서를 이은 선이에요. 실제 이동 경로가 아니에요." 표시. 휠은 페이지 스크롤, +/− 버튼으로 확대·축소.
- 좌표 문제: 반송공원(2907087)처럼 표시 범위를 벗어난 장소는 목록에 '지도 위치 확인 필요', 지도 아래 "N번 장소는 지도에서 뺐어요". 번호는 일정 순서 그대로 유지(1, 3처럼 건너뜀).
- 날씨: `/api/weather`를 부산 대표 격자로 한 번 호출(이미 시작한 여행은 오늘부터). 탭마다 ☂ 비/눈 예보 · 비 예보 없음 · 예보 전 · 예보 자료 없음 · 강수 확인 어려움 · 날씨 확인 실패 · 지난 날짜를 구분. 탭 아래에 "부산 대표 지점(격자 98,76) 기준 · 발표 시각 · 장소마다 다를 수 있어요".
- 기간이 줄어 보던 일차가 사라지면 남은 마지막 일차를 보여주고 알린다. 화면 안 '조건 바꾸기'로 기간을 줄이면 기존 규칙의 "N일차 장소 M곳이 날짜 없는 곳으로 옮겨졌어요" 알림.
- 이동 확인·날씨 확인은 비활성 '준비 중' 버튼. 와이어프레임은 휴대폰 하단 고정 막대지만, 누를 수 없는 버튼이 화면을 계속 가리지 않도록 지도 아래 일반 위치에 두었다(해당 화면 구현 때 하단 고정으로 바꿀지 결정).
- `/explore`의 '날짜에 배치하기 · 준비 중'(데스크톱 후보함·휴대폰 하단 막대)을 `/schedule` 링크로 교체.

## 근처 추천 추가 — 2026-10-25

브랜치 `feat/schedule-nearby` (← `origin/main` `f8be055`, PR #10 병합 후). 사용자가 시안 화면을 보고 "괜찮다"고 확인.

- 그날 일정 아래 "근처에 이런 곳도 있어요": 그날 장소 중 가장 가까운 곳에서 **직선거리 2km 안**, 후보함·일정에 없는 장소를 가까운 순 **최대 3곳**. "○○에서 약 1.0km · 분류"와 "실제 이동 거리는 다를 수 있어요" 표시.
- '+ N일차에 넣기'는 기존 `tripActions.addToDay` 하나로 후보함 담기와 그날 맨 뒤 넣기를 함께 한다.
- 아직 날짜 없는 곳: 그날 장소와 2km 안인 곳을 가까운 순으로 앞에 두고 "N일차 ○○에서 약 1.5km" 표시. 나머지는 담은 순서 유지. 날짜 탭을 바꾸면 그날 기준으로 다시 정렬.
- 지도: 추천 장소는 흰 동그라미, 일정 장소와 함께 보이도록 지도 범위를 맞춘다.
- 그날이 비었거나 2km 안 장소가 없으면 추천 줄을 숨긴다. 좌표가 잘못된 장소(반송공원)는 기준·추천 모두 제외.
- 이야기·도슨트 여부는 표시하지 않는다(검수 전). 거리 계산은 `scheduleModel.ts`의 `distanceKm`(직선거리), 테스트 4개 추가.
- 데이터 기준: 지도 표시 가능 407곳 중 1.5km 안에 다른 장소가 하나도 없는 곳 26곳, 중간값 8곳. 개금벚꽃길은 가야공원 약 1.05km·한국신발관 약 1.5km.

확인: 테스트 102개·린트·빌드 통과. 1440·390에서 개금벚꽃길 1일차 기준 가야공원 추천, 한국신발관 앞으로 정렬, 추천 넣기 후 후보함·일정 반영, 빈 날 숨김, 가로 넘침 없음.
