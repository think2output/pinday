2026-10-24 · Claude Code 작성 · **확정 (2026-10-24 사용자 확인)**. 코드는 `scripts/build-places.mjs`, 결과는 `data/places/places.json`.

- 사진 저작권 표시: 공공누리 1유형 134곳, 3유형(변경금지) 190곳, 표시 없음 27곳(관광지 기준). 3유형 사진은 자르거나 덧칠하지 않는다(기획서 11장).

## 정한 것

1. 관광지 + 문화시설 중 **박물관·기념관·전시관·과학관·미술관·수족관**만 넣는다. 모자라면 문화시설 전부로 넓힌다.
2. 레포츠는 넣지 않는다.
3. 한 장소가 여러 취향에 들어갈 수 있다.
4. 일반 회사·업체로 보이는 5곳(주식회사 놀핏, 주식회사감천아울, 주식회사뷰티홀릭, 주식회사어반힐링, 주식회사피알아이피)과 오션블루 가덕휴게소는 뺀다.

결과: **408곳** (관광지 345, 문화시설 63). 16개 구·군 모두 있음(가장 적은 곳: 사상구 6, 연제구 7).

| 취향 유형 (코드 id) | 맞는 분류 (중분류 > 소분류) | 장소 수 | 예시 |

| 광안리 노을 감상가 (`sunset`) | 자연경관(하천‧해양) > 해변. 해수욕장 · 해안절경 · 섬 · 항구/포구 / 랜드마크관광 > 다리 / 대교 · 분수 · 등대 / 도시공원 > 주제공원 | 58 | 광안리해수욕장, 다대포해수욕장, 광안대교, 민락수변공원 |
| 동래성 시간 여행자 (`history`) | 역사유적지 (전부) / 역사유물 > 탑ㆍ비석ㆍ기념탑 / 종교성지 (전부) / 전시시설 > 박물관 · 기념관 | 93 | 동래읍성지, 복천동 고분군, 충렬사, 범어사, 임시수도기념관 |
| 태종대 파도 탐험가 (`wave`) | 자연경관(하천‧해양) > 해안절경 / 랜드마크관광 > 타워 / 전망대 / 자연경관(산) (전부) / 자연공원 > 지질공원 · 생태관광지 · 자연휴양림 / 테마공원 > 테마파크 / 기타체험 > 유람선/잠수함관광 | 65 | 태종대, 이기대, 황령산 전망대, 금정산 |

- 여러 취향에 들어가는 곳은 6곳(해안절경 = 노을 + 탐험, 근대건축물 = 골목 + 역사).
- 어느 취향에도 안 들어가는 곳 147곳: 도시공원(근린·시민·소공원), 웰니스, 산업관광, 기타체험, 전시관·미술관·과학관 등. 취향순 정렬에서 뒤쪽에 이름순으로 나온다.
- 지금은 분류 단위 규칙이라 장소마다 섬세하지 않다(예: 노을 명소 전망대도 탐험가로만 분류). 필요하면 나중에 장소 id별 예외를 추가한다.

## 실내 / 야외 (날씨 대안용)

| 구분 | 분류 |
| --- | --- |
| 실내 (107곳) | 전시시설 전부(박물관·기념관·전시관·과학관·미술관) · 수족관 / 웰니스관광 (온천·찜질방·스파 등) / 기타문화관광지 > 기타문화시설 (79곳) + 장소별 예외 28곳 |
| 야외 | 그 밖의 모든 분류 |

- 전망대·테마파크·산업관광·건물·유람선은 장소마다 실내/야외가 다르다. 기본은 야외로 두고, 확인된 실내 장소만 `INDOOR_IDS`에 추가한다.
- 2026-10-25 날씨 대안 작업에서 28곳을 `INDOOR_IDS`에 넣었다(목록과 근거는 `scripts/build-places.mjs`). 기준: TourAPI 소개 글에 방문객이 머물 수 있는 실내 공간(체험관·전시실·실내 놀이시설·실내 전망대·건물 층수)이 적힌 곳. 야외가 함께 있어도 실내에서 지낼 수 있으면 넣는다(사용자 결정). 공원·거리·사찰·배처럼 실내가 부속 시설뿐인 곳은 넣지 않았다.
- 넣지 않은 곳 예: 롯데월드 어드벤처 부산(일부 어린이 놀이기구만 실내), 더베이101, 역사의 디오라마, 부산영화촬영스튜디오(관람 가능 여부 불명), 자갈치 크루즈, 스포원파크. 부산타워는 장소 목록에 없다.
