# 경로 API

2026-10-25. 공식 규격: https://developers.kakao.com/docs/ko/kakaomap/rest-api

`GET /api/route?from=장소ID&to=장소ID&mode=transit` (`mode=walk`는 도보).

- 수단 생략은 대중교통. 자동차·그 외 조건·중복 조건은 400.
- 실제 장소 목록의 서로 다른 두 장소만 허용. 없는 장소 404, 지도 표시 범위 밖 좌표 422.
- 서버의 `KAKAO_REST_API_KEY`만 사용. 키 미설정 503. 화면으로 키나 원래 오류를 보내지 않는다.
- 대중교통은 카카오 응답의 첫 경로, 도보는 도보 API 결과를 사용한다. 대중교통 실패/결과 없음이 도보로 자동 변경되지는 않는다.
- 성공: `{ from, to, leg }`. `leg.kind`는 `transit` 또는 `walk`. 시간은 초→분 반올림, 최소 1분. 대중교통은 단계별 수단·노선·승하차·정류장 수·선 좌표, 도보는 거리(m)와 선 좌표를 반환한다. 선은 지도 표시용으로 점을 일부 줄인다.
- 오류: `{ error: { code, message } }`. 외부 429는 `ROUTE_QUOTA`(429), 결과 없음은 `ROUTE_NOT_FOUND`(404), 통신·시간 초과·기타 실패는 `ROUTE_UNAVAILABLE`(502). 각 외부 호출 제한시간 8초.
- HTTP 응답은 `no-store`. 성공 결과만 서버 프로세스 메모리에 구간+수단별 6시간·최대 500개 저장, 동시 중복 요청 공유. 프로세스 재시작/다른 서버에서는 공유되지 않는다. 브라우저는 현재 페이지가 열린 동안 성공 요청을 재사용하고 오류는 저장하지 않는다.
- 사용자 제공 앱 관리 화면(2026-10-25 12:00 집계): 대중교통 33/1,000건, 도보 5/1,000건. 해당 앱의 일간 쿼터 분모는 각각 1,000, 초기화 안내는 매일 00:00. 스냅샷이며 모든 앱의 공통 한도·무료 제공량·초과 과금 정책을 의미하지 않는다. 코드·화면에는 숫자를 고정하지 않는다.
