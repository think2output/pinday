# 오늘의 부산 이야기 듣기 — 2026-10-25

> 최신 변경: 입구·모달 문구를 ‘오늘의 부산 이야기 듣기’로 변경. 선택할 카드가 있는 모달을 열면 약 0.95초 카드 포개기 → 섞기 → 펼치기 연출을 적용했다. 셔플 중 선택 불가·기회 차감 없음, 움직임 줄이기·0/1장은 생략. 결과 재열기·이야기 상세의 명시적 듣기 시작은 유지한다.

브랜치 `feat/random-pin`, 기준 main `d4fac7c`(취향 테스트 PR #18 병합). 사용자의 ‘기능만 있고 재미가 부족하다’는 피드백으로 홈 아래 결과를 제거하고 카드 선택 모달로 바꿨다.

## 현재 흐름
- 배너를 누르면 PC는 가운데 모달, 휴대폰은 전체 화면. 섞인 이야기 카드 최대 3장 중 한 장을 고른다. 실제 서로 다른 장소를 배정하며 카드 수는 지역의 승인 장소 수에 맞춘다.
- 선택 카드는 뒤집히고 나머지는 흐려지며 물러난다. 약 1.45초 뒤 장소 사진·첫 문장과 노란 핀 도장을 공개한다. 움직임 줄이기 설정에서는 즉시 결과. 자동 음성 없음.
- 홈 높이는 바뀌지 않으며 X/Escape로 닫으면 배너 포커스·기존 스크롤·스크롤 잠금을 복구한다. 열기·닫기·카드 받기는 차감하지 않는다.
- 카드 선택에만 1회 차감, 페이지당 3회. 빠르게 같은 카드를 여러 번 눌러도 1회만 차감한다. 새로고침 시 초기화. 3회 뒤 마지막 결과를 다시 열 수 있다.
- 승인·자동 검사 통과한 공개 도슨트 6곳만 서버에서 전달. 선택 구·군 기준이며 선택 없으면 부산 전체. 직전 장소 제외, 0곳 안내·1곳 선택 후 재선택 방지. 다른 지역으로 자동 확장하지 않는다.
- 지역 변경은 횟수를 초기화하지 않는다. 이전 범위의 결과는 숨긴다. 연출 중 범위가 바뀌면 이전 결과를 표시하지 않으며 이미 쓴 기회는 유지한다.
- 결과에서 이야기 상세로 이동하거나 후보함에 명시적으로 담는다. 기존 취향·지역·기간·일정은 유지한다. 이미 담은 장소는 담기 비활성.
- 사진은 원본 비율 `object-contain`과 출처·이용 유형을 유지한다. 뒤집기·기울이기는 자체 핀 그림 카드에만 적용한다. 원본 사진에 변형 없음.

## 카드 셔플 추가 검증

- `Draw.phase`에 `shuffling` 추가. 950ms 동안 카드가 가운데 포개져 좌우로 섞인 뒤 기존 3장 배치로 펼쳐진다. 연출은 자체 상징 카드에만 적용한다.
- 셔플 중 선택을 막으며 횟수는 변하지 않는다. 닫고 선택 카드 재열기·다른 카드 받기도 연출, 결과 화면 재열기는 결과 유지. 지역 변경 때 이전 셔플이 다른 지역 결과를 덮어쓰지 않도록 범위를 확인한다.
- `node scripts/qa-pin.mjs`의 390/1440 검증 통과: 셔플 애니메이션·비활성 선택·열기/셔플 차감 없음, 기존 카드 뒤집기·3회 제한·마지막 결과·저장 유지·0/1곳·움직임 줄이기. 테스트 150개·빌드 통과, 린트 기존 경고 1건. 경로/날씨 요청 0건.
