# 오늘의 핀 뽑기 — 2026-10-25

브랜치 `feat/random-pin`, 기준 `origin/main` = `d4fac7c`(취향 테스트 PR #18 병합). 홈 아래 ‘오늘의 핀 뽑기’를 누르면 같은 화면 안에서 연출과 결과가 펼쳐진다.

## 동작
- 서버 `listDocents()`가 공개 승인·자동 검사 통과한 6곳만 홈에 전달한다. 원문 근거나 미검수 해설을 뽑기 후보로 쓰지 않는다. 새 API 호출·실시간 해설 생성 없음.
- 선택 구·군의 승인 장소만, 선택 없으면 부산 전체. 지역·취향·기간은 뽑기가 바꾸지 않는다. 직전 장소는 다음 후보에서 제외한다.
- 페이지당 최대 3회. 새로고침하면 초기화. 지역 변경은 횟수를 초기화하지 않는다. 실제 장소를 고른 클릭부터 1회 차감하고, 연출 중 클릭 및 빠른 연속 클릭으로 초과하지 않도록 ref와 비활성 상태로 막는다.
- 일반 설정은 약 1.5초 동안 해당 범위의 장소 이름을 보여주다가 결과. `prefers-reduced-motion: reduce`는 연출 없이 결과 표시. 이름 연출은 화면 읽기에서 제외하고 뽑는 중 안내만 제공한다.
- 결과는 사진·구/분류·이름·승인 해설 첫 문장. ‘이야기 읽고 듣기’는 해당 도슨트 상세로 이동하며 거기에서 듣는다(자동 음성 없음). ‘후보함 담기’를 누를 때만 기존 `addCandidate` 호출. 이미 담겨 있으면 비활성, 일정은 변경하지 않는다.
- 사진은 `object-contain`, 원래 비율 유지. 출처·공공누리 유형 표시. 사진이 없으면 안내. 사진을 자르거나 기울이지 않는다.
- 0곳: 공개된 도슨트 없음·둘러보기 안내, 기회 차감 없음. 1곳을 이미 뽑음: 그 결과 유지·추가 뽑기 비활성/안내, 기회 추가 차감 없음. 다른 지역으로 자동 확장하지 않는다.
- 지역 변경 시 이전 범위 결과는 숨기고 새 지역에서 다시 뽑도록 안내. 연출 도중 바꿔도 이전 지역의 결과를 현재 결과처럼 보여주지 않는다. 연출 시작 때 쓴 1회는 유지하되 보지 못한 중단 결과를 직전 결과로 기록하지 않아 원래 지역으로 돌아왔을 때 뽑기가 막히지 않는다.
- 3회를 썼으면 후보가 있는 경우 후보함 확인(일정 화면), 없는 경우 먼저 후보에 담도록 안내한다.
