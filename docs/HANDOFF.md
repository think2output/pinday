- 사용자 지적: AI 도슨트 메뉴의 목록 썸네일 크기가 여전히 다름. 앞선 작업은 상세 사진을 맞췄으나 목록 화면에는 자동 너비가 남아 있었다.

- 사진 없는 25의용단도 같은 3:2 영역에 ‘등록된 사진이 없어요.’ 표시. 카드 제목 최소 높이와 설명 두 줄(48px)을 맞추고 불필요한 block을 제거했다.
- 실제 홈 상단 AI 도슨트 메뉴로 들어가 6개 카드를 모두 스크롤하며 사진 로딩과 크기를 확인했다. 휴대폰 390px: 358×238.7px, PC 1440px: 416×277.3px. 사진 5개·빈 사진 안내 1개 모두 같은 영역.
- 키보드 Enter로 상세 이동·가로 넘침 없음·여행 저장 정보 변경 없음·경로/날씨 요청 0건 확인.
- 재현: node scripts/qa-docent-thumbnails.mjs. 사진: docs/design/docent-list/list-390.png, list-1440.png.
- 테스트 150개·빌드 통과. 린트 오류 0, 기존 TasteResult.tsx 음성 effect 의존성 경고 1건. 이번에는 목록 전용 검증을 수행했으며 상세 검증과 혼동하지 않는다.

## 메인 화면의 현재 결정

### 지도와 선택

- 실제 부산 해안선·구/군 경계를 유지한다. 사용자가 임의 다각형 윤곽을 거부하고 실제 지도 참고를 제시했다.
- SGIS 2020 경계의 StatGarten 변환 자료를 고정 커밋에서 사용. 원본 path 16개·섬·상대 크기 유지. 출처·MIT 원문: data/maps/README.md, LICENSE.
- 넓은 9개 구만 명소 상징 선화 표시, 작은 7개 구는 이름만. 선화 원본은 16개 준비돼 있지만 모두 표시하려고 지형을 바꾸지 않는다.
- 지도 확대/축소·지도 안 스크롤·지역 드롭다운 없음. 터치/클릭·Tab/Enter/Space로 경계를 직접 선택한다. 작은 실제 구의 터치 영역 자체가 44px이라고 주장하지 않는다.
- 클릭 시 흰 사각 테두리 없음. 키보드 포커스는 실제 경계의 노란 선.
- 핀은 구 이름 바로 위 가운데. 새 선택에 0.62초 수직 낙하·작은 튕김, 발끝에서 0.9초 두 겹 물결. 저장된 핀 재열기에는 재생하지 않는다. 움직임 줄이기는 즉시 표시.
- 마우스/터치를 따라오는 노란 조명이 지도 표면과 주변에 비친다. 지역 태그·기간·시작 버튼·기존 저장소 유지.
- 홈 상단과 이야기 앞 여백을 줄였다. 기본 상태 이야기 시작 위치: 390px 화면 903px, 1440px 화면 756px(이전 1,094/1,134px).

### 이야기 카드와 배너

- 홈 카드는 공개 승인·자동 검사 통과 도슨트만 사용한다. 임시 ‘이번 주’는 사진이 있고 서로 다른 구인 최대 4곳. 수동 선정 기준은 미정.
- 카드 전체 → 같은 장소 /docent/{id}, 전체 보기 → /docent. 지역에 공개 해설이 없으면 준비 중 안내 + /explore 링크. 지역 자동 확장·미검수 글 공개 없음.
- 카드 사진 영역 높이: 휴대폰 192px, PC 208px. 원본은 contain으로 표시. 앞쪽 지도/핀 장식 제거, 뒤 종이와 조명 유지. 호버·키보드 포커스는 뒤 조명만 밝아진다.
- 글 순서: 구 → 장소명 → 설명 두 줄·말줄임 → ‘이야기 들으러 가기 →’. 출처·유형은 그 뒤 작은 글씨. 글 왼쪽 정렬, 설명 48px 고정.
- 취향 테스트 배너: ‘어디로 가야 할지 모르겠다면?’.
- 랜덤 이야기 배너/모달: ‘오늘의 부산 이야기 듣기’. 선택 카드가 있는 모달 열기·다른 카드 받기에서 0.95초 카드 포개기→셔플→펼치기. 셔플 중 선택 불가·차감 없음. 0/1장·움직임 줄이기는 생략.
- 실제 카드 선택만 페이지당 3회 중 1회 차감. 직전 장소 제외, 지역 변경으로 초기화 안 함. 3회 뒤에도 마지막 결과 재열기, 새로고침 시 횟수 초기화.
- 후보는 명시 클릭으로만 담기. 기존 일정 유지. 음성 자동 재생 없음.
- 홈 첫 문구·‘이번 주’ 수동 선정·공통 메뉴 정리는 아직 별도 후속 후보.

- 여행은 계정 없이 브라우저 저장 한 개. 일차 기준 최대 14일, 같은 장소는 하루에만. 기간 축소 시 사라진 일차 장소는 날짜 없는 곳으로 이동, 후보는 보존.
- 저장·수정은 기존 tripActions만. 초기화·되돌리기·다른 탭 변경·중복 규칙을 임의 변경하지 않는다.
- 날씨는 부산 대표 격자. 예보 전·결측·오류를 ‘비 없음’으로 만들지 않는다. 대안 교체는 사용자 클릭 때만, 가까운 실내 최대 3곳·직선거리 표시. 자세한 판단/되돌리기는 관련 QA.
- 경로 수단은 구간별 대중교통·도보, 선택은 화면 안에서 유지. 자동차·새 API 활성화는 미정. 확인하지 않은 무료 한도/시간을 화면에 쓰지 않는다.
- 도슨트는 publishable=true + humanReview approved + 자동 검사 0건만 공개. 한 문장 해설인 해운대는 비공개. 근거 없는 문장·미검수 자료를 이야기로 채우지 않는다.
- 해설 추가는 AI 문장별 원문 대조 → 짧은 표 보고 → 사용자 승인. 유료 호출은 예상 비용과 최소 범위를 먼저 설명. 공식 음성·최근 소식은 이용 조건 확인 전이라 없음.
- 사진은 공공누리 유형·출처 유지, 변경금지 사진은 자르거나 기울이거나 덧칠하지 않는다. contain으로 원본 전체 표시.
- 반송공원(2907087)은 원본 좌표가 부산 밖. 원본 수정 없이 지도·거리 계산에서 제외.
- 디자인은 흰 바탕·먹색·노란 조명·모서리 0·Wanted Sans/Pretendard. 색은 tokens.css 이름만 사용. 둥근 카드·크림 페이지 바탕·구분선 남발·영문 고정폭 라벨·형광펜·홈 큰 내 여행 카드 금지.
- Next.js 16.4.3 / React 19.3.0, cacheComponents 사용. 코드 작성 전 node_modules/next/dist/docs/ 읽기. useTrip 화면은 Suspense, 날짜는 mounted 이후, 동적 경로는 generateStaticParams 한 개 이상.
- vitest에는 @/ 별칭이 없으므로 상대 경로 import.
- .env·키는 읽어 출력하거나 커밋하지 않는다. .vscode는 사용자 개인 설정. AGENTS.md의 Next.js 자동 안내 블록은 유지한다.
