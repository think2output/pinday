3. 화면 수정 브랜치 feat/home-map-illustrations는 PR #21로 main(a973334)에 병합됐어. 현재 비교 문서 브랜치는 feat/service-evolution-docs야. 문서 브랜치의 병합 여부는 다시 확인하고 기존 변경을 보존해줘.
4. 현재 상태를 짧게 알려주고 다음 범위는 나와 정해줘. 내가 요청한 작업은 그 범위 안에서 진행해줘.

## 지금 상태
- 내가 지정한 이전 PinDay는 https://pinday-web.vercel.app/야. 현재와의 차이는 docs/SERVICE_EVOLUTION.md에 정리했어. 기존 기능도 많았으니 전부 새로 만들었다고 설명하지 마.
- 주요 화면은 모두 구현됐어: 홈, 어디 갈까?, 언제 갈까?, 어떻게 갈까?, 날씨 대안, 취향 테스트, AI 도슨트 목록/상세, 내 여행.
- Vercel 첫 배포 주소는 https://pinday-five.vercel.app/. 배포 후 카카오 지도 표시를 확인했어. 작업 브랜치의 최신 수정이 운영에 반영됐는지는 별도 확인이 필요해.
- 최근 작업은 실제 부산 윤곽 지도·핀/물결·노란 조명, 홈 사진/카피/이야기 연결, 카드 셔플, 도슨트 사진 정리야.
- 최신 지적은 AI 도슨트 ‘목록 메뉴’ 썸네일이었어. 목록을 3:2로 통일했고 scripts/qa-docent-thumbnails.mjs로 390/1440 화면의 6개 카드를 직접 확인했어. 상세만 확인하고 목록까지 확인했다고 말하지 마.
- 테스트 150개·빌드 통과. 린트는 오류 0, 기존 취향 음성 경고 1건. 정확한 최신 상태는 HANDOFF가 기준이야.

## 지킬 것
- 한국어로 짧고 쉽게, 결론부터. 난 PM이고 코딩 초보야.
- 방향이 애매하면 실제 화면과 사진을 보여줘. 홈/목록/상세 중 확인한 화면을 구분해줘.
- 공통 저장소·디자인 값·공통 컴포넌트는 수정 전에 먼저 물어봐. 기존 tripActions를 그대로 써줘.
- 실제 지도 윤곽을 임의 블록으로 바꾸거나 지도 확대·드롭다운을 다시 넣지 마. 작은 구 아이콘은 빼도 돼.
- 홈 카드는 구 → 장소명 → 설명 두 줄·말줄임 → 이야기 들으러 가기 순서. 승인 도슨트 상세로 연결해줘.
- 사진은 출처/유형과 원본 비율을 유지하고 변경금지 사진은 자르거나 기울이거나 덧칠하지 마.
- 승인 해설만 공개. 자료에 없는 사실을 만들거나 자동으로 콘텐츠를 늘리지 마. 유료 호출은 예상 비용부터 말해줘.
- 브라우저 확인은 localhost:3000, 390/1440, 별도 프로필로. 내 저장 정보를 건드리지 마.
- .env·키를 출력/커밋하지 말고 .vscode도 건드리지 마. main 직접 push·force push·브랜치 삭제 금지.
- 완료하면 관련 검증·HANDOFF/DECISIONS·커밋·작업 브랜치 push·PR 링크까지 정리해줘. 병합은 내가 해.
