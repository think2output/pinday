이번 범위:
1. 날짜 탭·그날 일정·아직 날짜 없는 곳·그날 지도 네 영역.
2. 날짜 없는 곳을 현재 선택한 일차에 바로 추가. 다른 일차로 옮기기·일정에서 빼기·드래그 및 키보드 순서 변경.
3. 그날 지도에 순서 번호·점선 표시. 실제 길찾기 경로처럼 표현하지 마. 지도 실패에도 편집은 가능해야 해.
4. 날씨 API로 날짜 탭 강수 표시. 예보 전·결측·오류를 구분하고 날씨 실패가 편집을 막지 않게 해줘. 대표 지점 예보는 그 범위를 밝혀줘.
5. /explore의 “날짜에 배치하기”를 /schedule로 연결. /trip 이어서 계획하기와 헤더 메뉴 진입도 확인.
6. 아직 없는 경로·날씨 대안·도슨트 화면은 준비 중 안내. 미검수 83곳을 이야기 있는 장소로 표시하거나 해설을 만들지 마.
