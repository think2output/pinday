# 이야기형 취향 테스트 — 2026-10-25

브랜치 `feat/taste-story-tour`, 기준 `origin/main` = `951e8e3`(PR #17 병합). 실제 화면 `/taste`.

## 흐름과 콘셉트
- ‘당신에게 켜지는 부산의 이야기’ 첫 장 → 아침/오후/해 질 녘/하루 정리/귀가 5장면 → 기존 4유형 결과.
- 먹색 전시실에서 4개의 선화 상징 중 마음이 가는 장면 선택. 흰 결과 화면에서 유형·설명·키워드·부산 대표 3곳 코스·듣기/읽기로 이어진다. 자체 SVG이며 외부 이미지 생성은 사용하지 않았다.
- 사용자 요청에 따라 근거리 코스가 아닌 부산 대표 장소를 넓게 묶었다. 이동 시간·최적 경로·영업시간·당일 방문 가능성은 추정하지 않는다. 일정에 담은 뒤 기존 ‘이동 확인’에서 확인한다.

| 유형 | 대표 코스(실제 places.json 이름/ID 기준) |
| --- | --- |
| 이바구길 골목 산책자 | 168계단 → 부산 감천문화마을 → 흰여울문화마을 |
| 광안리 노을 감상가 | 다대포해수욕장 → 부산 송도해수욕장 → 광안리해수욕장 |
| 동래성 시간 여행자 | 동래읍성지 → 복천박물관 → 범어사(부산) |
| 태종대 파도 탐험가 | 이기대 → 오륙도 스카이워크 → 태종대 |

분류만으로 자동 생성한 코스가 아니라 기존 4유형의 주제에 맞춰 편집한 장소 묶음이다. 168계단은 원본 취향 태그가 없지만 승인 도슨트가 있는 이바구길 유형의 대표 시작점으로만 쓴다. 원본 분류는 변경하지 않았다. 장소 데이터가 없어지거나 좌표가 이상하면 추측해 채우지 않고 남은 장소만 표시한다.

## 저장·도슨트 연결
- 5문항 완료 전에는 여행 정보 변경 없음. 완료 시 취향만 저장, 탐색의 취향순 정렬에 반영.
- 동점은 최다 동점 유형 중 최근 답 우선. 마지막 답이 최다 유형이 아닌 경우 그 답으로 결과를 덮지 않는다.
- 결과 코스는 부산 전체 대표 코스. 현재 선택 지역 밖에 포함되면 안내하고 기존 지역은 유지.
- 날짜 선택 창은 기존 장소 수와 새로 담을 장소를 표시. 취소 시 변화 없음. 확인 시 새 장소만 기존 일정 뒤에 추천 순서로 추가. 이미 다른 날에 있는 장소도 그대로 두며 중복·이동·덮어쓰기 없음.
- 기존 `tripActions`만 사용. 공통 저장소·토큰·SiteHeader 수정 없음. 홈 취향 카드와 탐색 준비 중 문구는 `/taste` 진입점으로 갱신.
- `listDocents()`가 공개 승인·자동 검사 통과한 해설만 제공. 듣기는 기존 `useSpeech`를 수정 없이 사용. 자동 재생 없음. 코스의 승인 해설 우선, 없으면 같은 취향의 승인 해설을 ‘코스 밖’으로 명시한다(노을 유형의 태종대).
